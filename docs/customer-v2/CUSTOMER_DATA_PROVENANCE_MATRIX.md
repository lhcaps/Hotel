## Audit decisions

- `MEDIA_BUSINESS_AUTHORITY=INVALID`: `apps/web/src/content/peace-home-physical-rooms.ts` currently owns names, tiers, and static price fallbacks. Its successor may own only code-keyed media and public slugs.
- `RANDOM_ROOM_IMAGE_MAPPING=CONFIRMED`: `publicRoomImage(roomTypeId)` sums UUID character codes and uses modulo three. It creates provable cross-room imagery.
- `PUBLIC_ROOM_TYPE_CODE=ABSENT`: the database has `room_types.code`, but `@room/contracts/public-room-catalog` does not expose it.
- `PROPERTY_ARRIVAL_CONFIGURATION=ABSENT`: the current schema intentionally stores only a provider credential reference and has no property address, support contact, Wi-Fi, pass, arrival, or preparation configuration.
- `UNAVAILABLE_DATA_POLICY=REQUIRED`: every listed `UNMODELED` field must be absent with an honest customer-safe state until its authoritative vertical is implemented.
