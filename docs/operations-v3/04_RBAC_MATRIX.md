# RBAC correction grounded in the current repository

## Current authorization model

- Top-level user roles are `ADMIN`, `SUPER_ADMIN`, `ROOM_STATUS_VIEWER`, and `CUSTOMER` in `packages/database/src/schema.ts:55-63`; policy docs group authentication as CUSTOMER/ADMIN/SYSTEM_WORKER, with the worker using scoped workload identity.
- The permission registry is `packages/auth/src/permissions.ts:9-73`. It includes booking, room, operations, maintenance, payment, catalog, pricing, provider, admin-account, department, and audit permissions.
- `ROLE_PERMISSIONS.ADMIN` and `ROLE_PERMISSIONS.CUSTOMER` are empty; `SUPER_ADMIN` receives the full registry; `ROOM_STATUS_VIEWER` receives exactly seven read permissions (`permissions.ts:78-93`).
- `apps/api/src/auth/auth.providers.ts:38-75` derives active membership access, ranks `SUPER_ADMIN` above `ROOM_STATUS_VIEWER`, and supplies server-derived permissions. `AdminPermissionGuard` uses `@RequirePermissions` metadata and denies missing profile/permission (`apps/api/src/auth/admin-permission.guard.ts:30-49`).
- `admin_departments`, `admin_profiles`, and `admin_memberships` are real tables, but department membership alone is not a permission grant. There is no property column on `admin_memberships`; current property scope is the selected/current property boundary, not a complete multi-property membership model.
- Session/profile contract: `packages/contracts/src/admin.ts:45-59`; registration/route coverage: `apps/api/src/auth/permissions.decorator.ts`, `apps/api/test/admin-route-permission-inventory.test.ts`, `packages/auth/test/permissions.test.ts`, and `apps/web/test/admin-navigation.test.tsx`.

## Accepted `ROOM_STATUS_VIEWER` behavior

Preserve exactly: `catalog.property.read`, `catalog.room.read`, `catalog.room.status.read`, `catalog.maintenance.read`, `rooms.read`, `room_operations.read`, and `maintenance.read`. It remains denied booking lifecycle, payments/revenue, customer/admin accounts, providers, audit, pricing mutations, and all room mutations. The existing tests assert these grants/denials and the web test renders only the room-status surface. Department membership alone does not expand this set.
