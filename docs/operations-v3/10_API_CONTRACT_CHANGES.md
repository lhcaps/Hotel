# API contract change map

Current status: the additive B0 contract is implemented locally. The
multi-night request, structured availability states, quote V2 pricing snapshot,
customer/admin stay representation, and policy-admin routes are server-owned
and feature-gated. The public multi-night gate defaults OFF. The table below is
the authoritative local implementation map; historical design intent is kept
in the compatibility notes.

All routes remain under `/api/v1`. Changes below are design-only and must be additive where old clients can continue to parse their current fields.

## Prohibited response fields

Never add `physicalRoomCode` to public/customer responses, provider credential secrets, internal inventory ids not needed by the client, client-supplied role/permission claims, or client-authoritative amounts. The current privileged `RoomOperationsService` has an admin-only `physicalRoomCode` field; this existing admin boundary requires separate authorization review and is not a public/customer field.
