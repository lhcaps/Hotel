## Known limits and rollback

Unrelated local applications own the default web/API ports 3000 and 3001, so the Room Management smoke harness intentionally uses explicit Playwright-only ports 3100 (web) and 3101 (API). A separate sequential web run uses 3102 only to prove the unavailable-API state. The application defaults remain 3000 for web and 3001 for API; no fallback product port was introduced.

The execution environment rejected the required recursive deletion of workspace `node_modules` and generated output, so a literal deletion-based fresh install was not executed. The forced frozen-lockfile install above gives partial installation evidence only.

The worker connected to Redis in a real run. Its cleanup path has unit coverage; a non-interactive Windows `SIGINT` sent to a child process terminated the process before its final graceful-shutdown log could be observed, so that exact runtime signal proof remains outstanding.

The Phase 0 documentation baseline is committed and tagged locally as `phase-0-baseline`. After committing Phase 1, use `git revert <phase-1-commit>` for a recoverable rollback; use `git diff phase-0-baseline..HEAD` before selecting a partial rollback.
